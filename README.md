# بله‌پی | BalePay — پنل مدیریت

بازسازی کامل دموی [BalePay](https://houshinex.ir/balepay/balepay-demo.html) با **HTML / CSS / JavaScript خالص** — بدون هیچ فریمورک یا کتابخانه‌ای.

## اجرا

فایل `index.html` را در مرورگر باز کنید یا:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## ساختار پروژه

```
├── index.html      # ساختار صفحه (اسپرایت آیکون‌ها + ۶ بخش)
├── css/style.css   # استایل + سیستم تم ۸گانه (CSS Variables)
└── js/
    ├── data.js     # دیتای نمایشی (تراکنش‌ها، کاربران، تم‌ها، لاگ‌ها…)
    ├── charts.js   # موتور نمودار Canvas خالص (میله‌ای + دونات)
    └── app.js      # منطق پنل (روتر، فیلترها، شبیه‌ساز، تنظیمات…)
```

## امکانات

- **داشبورد**: کارت‌های آماری، نمودار فروش ۷ روزه (با تولتیپ)، دونات وضعیت سفارشات
- **تراکنش‌ها**: فیلتر (مشتری/تاریخ/وضعیت/پلتفرم)، حذف، مشاهده و خروجی CSV واقعی
- **پیام گروهی**: پیش‌نمایش زنده، ارسال تست و تاریخچه
- **تنظیمات**: ۷ تب (عمومی، پرداخت، پیام‌رسانی، قالب پیام، گزارشات، تم‌ها، تست و دیباگ)
- **شبیه‌ساز**: سناریوهای ثبت سفارش → آپلود رسید → تأیید/رد → Undo با چت تعاملی
- **۸ تم رنگی**: آبی بله، سبز مشکی، بنفش آبی، نارنجی سفید، قرمز مشکی، طلایی مشکی، فیروزه‌ای آبی، حالت تاریک (با ذخیره در localStorage)

## نکات فنی

- راست‌چین کامل (RTL) + اعداد فارسی
- فونت Vazirmatn (CDN + fallback سیستمی)
- روتر هش‌محور (`#/dashboard`، `#/settings` و…) — سوییچ آنی بخش‌ها
- نمودارها بدون کتابخانه، با پشتیبانی Retina و رسم مجدد هنگام تغییر تم/اندازه
- ریسپانسیو کامل (موبایل: منوی کشویی)
