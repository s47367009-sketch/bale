# بله‌پی | BalePay — پنل مدیریت + پلاگین وردپرس

بازسازی کامل دموی [BalePay](https://houshinex.ir/balepay/balepay-demo.html) با **HTML / CSS / JavaScript خالص** — بدون هیچ فریمورک یا کتابخانه‌ای.

## اجرا

فایل `index.html` را در مرورگر باز کنید یا:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## ساختار پروژه

```
├── index.html            # ساختار صفحه (اسپرایت آیکون‌ها + ۶ بخش)
├── css/style.css         # استایل + سیستم تم ۹گانه (CSS Variables)
├── js/
│   ├── data.js           # دیتای نمایشی (تراکنش‌ها، کاربران، تم‌ها، لاگ‌ها…)
│   ├── charts.js         # موتور نمودار Canvas خالص (میله‌ای + دونات)
│   └── app.js            # منطق پنل (روتر، فیلترها، شبیه‌ساز، تنظیمات…)
├── balepay.zip           # ⬇️ پلاگین وردپرس آماده نصب (در صفحه «درباره» لینک دارد)
└── plugin/balepay/       # سورس کامل پلاگین وردپرس (درگاه + ربات + پنل ادمین)
```

## امکانات پنل

- **داشبورد**: کارت‌های آماری، نمودار فروش ۷ روزه (با تولتیپ)، دونات وضعیت سفارشات
- **تراکنش‌ها**: فیلتر (مشتری/تاریخ/وضعیت/پلتفرم)، حذف، مشاهده و خروجی CSV واقعی
- **پیام گروهی**: پیش‌نمایش زنده، ارسال تست و تاریخچه
- **تنظیمات**: ۷ تب (عمومی، پرداخت، پیام‌رسانی، قالب پیام، گزارشات، تم‌ها، تست و دیباگ)
- **شبیه‌ساز**: سناریوهای ثبت سفارش → آپلود رسید → تأیید/رد → Undo با چت تعاملی
- **۹ تم رنگی**: سفید سبز (پیش‌فرض)، آبی بله، سبز مشکی، بنفش آبی، نارنجی سفید، قرمز مشکی، طلایی مشکی، فیروزه‌ای آبی، حالت تاریک — با ذخیره در localStorage

## پلاگین وردپرس (balepay.zip)

ZIP آماده نصب در ریشه همین سایت قرار دارد و از صفحه «درباره بله‌پی» (کارت «دانلود پلاگین وردپرس» یا دکمه سایدبار) قابل دانلود است. شامل:

- درگاه پرداخت کارت به کارت ووکامرس (کارت‌ها + شبا + مهلت پرداخت)
- اتصال همزمان ربات بله و تلگرام (اعلان سفارش جدید، رسید، تأیید/رد با دکمه Inline، Undo)
- وب‌هوک REST با Secret امن: `/wp-json/balepay/v1/webhook?platform=bale&secret=…`
- گزارش خودکار روزانه/هفتگی فروش (wp-cron)
- پنل مدیریت داخل پیشخوان وردپرس (همین پنل HTML)
- سازگار با HPOS ووکامرس

نصب: **افزونه‌ها ← افزودن ← بارگذاری افزونه ← balepay.zip ← فعال‌سازی** سپس فعال‌کردن درگاه در **ووکامرس ← پرداخت‌ها**.

## نکات فنی

- راست‌چین کامل (RTL) + اعداد فارسی
- فونت Vazirmatn (CDN + fallback سیستمی)
- روتر هش‌محور (`#/dashboard`، `#/settings` و…) — سوییچ آنی بخش‌ها
- نمودارها بدون کتابخانه، با پشتیبانی Retina و رسم مجدد هنگام تغییر تم/اندازه
- ریسپانسیو کامل (موبایل: منوی کشویی)
