# بله‌پی | BalePay — پلاگین وردپرس

درگاه پرداخت **کارت به کارت** ووکامرس با تأیید مدیر از طریق ربات **بله** و **تلگرام**.

## امکانات

| امکان | توضیح |
|---|---|
| 💳 درگاه کارت به کارت | نمایش کارت‌ها و شبا در صفحه سفارش |
| 🔔 اعلان خودکار | اطلاع‌رسانی سفارش جدید/رسید به مدیر و مشتری |
| ✅ تأیید از ربات | دکمه‌های Inline تأیید/رد داخل چت |
| ↩️ Undo | بازگشت تأیید/رد با یک کلیک |
| 🧾 آپلود رسید | ارسال عکس رسید در چت ربات توسط مشتری |
| 📊 گزارش خودکار | گزارش روزانه/هفتگی فروش برای مدیر |
| 🔗 اتصال دوگانه | بله + تلگرام همزمان |

## ساختار

```
balepay/
├── balepay.php                        # فایل اصلی، هوک‌ها، منوی مدیریت
├── includes/
│   ├── class-balepay-gateway.php      # درگاه پرداخت ووکامرس + تنظیمات
│   ├── class-balepay-bot.php          # API بله/تلگرام، اعلان‌ها، پردازش آپدیت
│   ├── class-balepay-webhook.php      # نقطه پایانی REST
│   └── class-balepay-report.php       # گزارش خودکار (wp-cron)
├── admin-panel/
│   ├── panel.php                      # پنل مدیریت (همان دموی HTML)
│   └── assets/                        # CSS / JS پنل
└── readme.txt                         # readme استاندارد وردپرس
```

## راه‌اندازی سریع

1. نصب: **افزونه‌ها ← افزودن ← بارگذاری افزونه** ← `balepay.zip`
2. فعال‌سازی درگاه: **ووکامرس ← پیکربندی ← پرداخت‌ها ← بله‌پی**
3. وارد کردن کارت‌های بانکی، توکن ربات‌ها و آیدی مدیر
4. ثبت وب‌هوک در BotFather:

```
https://YOUR-SITE/wp-json/balepay/v1/webhook?platform=bale&secret=YOUR-SECRET
```

مقدار `secret` هنگام فعال‌سازی به‌صورت خودکار ساخته می‌شود.

## جریان کار مشتری

`ثبت سفارش` ← نمایش کارت‌ها ← `‎/start` در ربات ← ارسال شماره سفارش (`#1234`) ← ارسال عکس رسید ← تأیید/رد مدیر ← اعلان نتیجه (+Undo)
